One childhood memory, distilled to a single sentence. The program (`main.py`, standard library only, fully deterministic) drafts three genuinely different candidates — steering Dad's old pickup down a dirt road, dinner by candlelight when the power went out, the squeak of an aunt's screen door on a rainy afternoon — scores each 0–5 against the judge brief's five criteria (nostalgia, concrete grounding, truly-lived detail, single clean sentence, lingering warm ache), and writes the strongest one to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). The winning line:

> Every August my father let me steer the old pickup down our dirt road while he worked the pedals, and I believed, for ten whole seconds, that I was the one driving us home.

Entry for the make.fun bounty [Make the AI Judge Feel Nostalgic: A Childhood Memory](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363) — write one sentence, at most 280 characters, that brings back a childhood memory.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
